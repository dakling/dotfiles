  <name>Task 1: Create package scaffold with minor mode and customization</name>
  <files>~/code/emacs-packages/claude-notify/claude-notify.el</files>
  <action>
Create the directory `~/code/emacs-packages/claude-notify/` and the file `claude-notify.el`.

The file MUST contain, in this order:

1. **Package header** with standard Emacs conventions:
   - `;;; claude-notify.el --- macOS notifications for Claude Code sessions`
   - Package-Requires: `((emacs "29.1"))`
   - Author, URL (https://github.com/dakling/claude-notify), Version 0.1.0

2. **Customization group** `claude-notify`:
   - Parent group: `tools`

3. **defcustom `claude-notify-backend`**:
   - Type: choice between `osascript-async` (default) and `ns-applescript`
   - Group: `claude-notify`
   - Docstring explains the tradeoff: osascript-async is fast (~10ms, async) but attributed to Script Editor; ns-applescript is slower (~700ms, blocks Emacs) but attributed to Emacs in System Settings

4. **Global minor mode `claude-notify-mode`**:
   - Use `define-minor-mode` with `:global t`
   - Group: `claude-notify`
   - Lighter: `" CN"` (shown in modeline)
   - On enable: message "claude-notify: notifications enabled"
   - On disable: message "claude-notify: notifications disabled"
   - The mode variable gates notification dispatch (checked in Plan 02's hook handler)

5. **AppleScript quoting helper** `claude-notify--applescript-quote`:
   - Takes a string, returns it quoted for AppleScript
   - Escapes backslashes and double quotes
   - Wraps in double quotes

6. **Async osascript backend** `claude-notify--send-osascript-async`:
   - Takes title, subtitle, body
   - Constructs AppleScript `display notification` command
   - Calls `start-process "claude-notify" nil "osascript" "-e" script`
   - This is the DEFAULT backend

7. **ns-do-applescript backend** `claude-notify--send-ns-applescript`:
   - Takes title, subtitle, body
   - Calls `ns-do-applescript` with the same AppleScript template
   - Wraps in `condition-case` to handle errors (e.g., not available on non-NS builds)

8. **Dispatch function** `claude-notify--send`:
   - Takes title, subtitle, body
   - Uses `pcase` on `claude-notify-backend` to dispatch to the correct backend
   - If `ns-applescript` is selected but `ns-do-applescript` is not `fboundp`, falls back to `osascript-async`

9. **Package footer**: `(provide 'claude-notify)` and `;;; claude-notify.el ends here`

Do NOT include hook handler, install-hook, or shell script logic -- those belong to Plan 02.

IMPORTANT conventions from CLAUDE.md:
- This is a standalone package, NOT part of Doom config
- Do NOT use `setq!` in the package itself (that's a Doom-config convention)
- Use standard `defcustom` / `define-minor-mode` patterns
